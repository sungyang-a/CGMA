# Result summaries

`expected/paper_tables.csv` indexes the aggregate values reported in the manuscript.
Raw experiment logs, per-sample probabilities, checkpoints, and representation dumps
are deliberately excluded from the public release.

`scripts/aggregate_results.py` is retained so users can parse logs generated by their
own runs:

```bash
python scripts/aggregate_results.py \
  --log_dir outputs/lmvd \
  --output_dir outputs/lmvd/aggregated
```
